openHT2

Свободная реализация движка Hard Truck 2 / «Дальнобойщики 2» на Rust и wgpu. Цель — 1:1 совместимость с оригиналом.

Статус

  • готовоЧтение .RES (141 из 141 файлов), .way (41 из 41), .b3d (45 из 45) и текстур .txr
  • готовоКонсольный инспектор ht2-tool и просмотрщик моделей на wgpu ht2-view
  • готовоПрототип: открытый мир из 39 районов, управляемый грузовик с данными из vehicle.tech, расшифрованные скрипты .sch
  • готовоПеренос физики оригинала: двигатель, автоматическая коробка, топливо, руль (сверено с оригинальным кодом на эмуляторе)
  • готовоПеренос шага физики машины целиком: шины, подвеска, покрытия дорог, кузов (сверено с оригиналом на эмуляторе)
  • готовоПеренос конструктора машины: массы, крепления колёс, постановка на землю (сверено с оригиналом на эмуляторе)
  • готовоМашина в игре работает на перенесённом коде: конструктор, шаг физики, колёса из узлов модели
  • в работеСтолкновения со сценой .b3d и типы покрытий, отрисовка колёс как в оригинале
  • планДороги по графам .way, интерфейс, звук
  • планФизика грузовиков, задания, торговля, ИИ

Скриншоты

Это работа самого движка openHT2 на данных установленной копии игры: открытый мир, гоночная трасса, грузовик, комбинат и арена.

Модели, текстуры и сцены на скриншотах принадлежат правообладателям оригинальной игры и показаны только для иллюстрации работы движка. В репозиторий они не входят.

Как это работает

openHT2 — это замена движка, а не отдельная игра. Он читает файлы вашей установленной копии игры и ничего в них не изменяет. Код и ассеты оригинала в проект не входят: форматы описываются clean-room, по самим файлам данных.

Попробовать

git clone https://github.com/LakoMoor/openHT2
cd openHT2
cargo run --release -p ht2-tool -- res-ls "<папка игры>/ENV/aa.res"
